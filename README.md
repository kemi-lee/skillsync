# SkillSync

![CI](https://github.com/kemi-lee/skillsync/actions/workflows/ci.yml/badge.svg)

SkillSync takes a job posting and a list of my skills. It tells me which required skills I have and which I'm missing, and says whether I'm a strong fit. If there are gaps, it asks if I want to learn them, and only then gives me a short learning plan.# skillsync
